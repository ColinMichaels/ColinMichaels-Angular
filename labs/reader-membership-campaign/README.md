# Reader membership campaign

Editable Remotion source for the ColinMichaels.com reader-account launch.

## Outputs

- Vertical 15-second promo video for Reels, Stories, and Shorts
- Platform-sized stills for Facebook, Instagram, Threads, X, LinkedIn, and YouTube Community

All typography, calls to action, timing, and composition sizes remain editable in `src/Composition.tsx`. The master generated artwork and the site’s local fonts live under `public/`.

## Preview and render

```bash
npm run dev
npm run render:social
npm run render:video
```

Rendered deliverables are written to `output/` and intentionally excluded from Git. Final campaign exports copied into the main project live under `src/assets/social/reader-membership/`.
