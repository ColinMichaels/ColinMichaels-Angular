# Welcome to Colinos OS

## Your Mission

Uncover hidden data, solve cryptic puzzles, and ascend through system levels. Can you unlock the Matrix Node?

---

## 🧠 Commands You'll Learn

- `ls` — List directory contents
- `cd <folder>` — Move between system folders
- `open <file>` — Read system logs or discover Easter eggs
- `chat ai` — Talk to a mysterious system assistant
- `run firewall-breaker` — Play the built-in arcade mini-game

---

## 💡 Tips for Success

> Look for patterns in filenames and fragments in corrupted logs.  
> Trust nothing. Explore everything.
