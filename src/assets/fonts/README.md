Self-hosted web fonts for ColinMichaels.com.

The font files in this directory are WOFF2 Latin and Latin Extended subsets downloaded from Google Fonts on 2026-07-02.

Families:

- Arimo
- K2D
- Lexend
- Source Sans 3

These assets replace runtime requests to `fonts.googleapis.com` and `fonts.gstatic.com`. Keep font declarations centralized in `src/styles/fonts.scss`.
